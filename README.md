# 墨笺

一款离线优先、可靠保存的手机写作应用。界面采用“纸墨书房”风格，支持所见即所得富文本编辑、本机多副本保存，以及 PDF、Word、JPG 三种导出格式。

## 隐私设计

- 无账号、无埋点、无云同步代码。
- Android 正式构建移除 `INTERNET` 权限。
- 文稿不加密，不依赖文稿密钥、指纹、面容或设备密码，打开应用即可使用。
- 文稿同时写入主副本和恢复副本；写入中还保留临时副本，启动时自动选择最新的完整数据。
- 数据仅保存在系统隔离的应用私有空间，不写入公共相册或下载目录。
- 默认阻止截屏和录屏；仅生成 JPG 的瞬间临时放行，分享完成后立即恢复。
- 只有用户主动选择导出时，明文文件才会交给系统分享面板；临时 Word/JPG 文件随后删除。

> 安全边界：当前设计优先保证文稿不会因密钥异常而无法打开。隐私依赖 Android/iOS 的应用沙箱与设备本身的系统锁；越狱、Root、恶意系统组件或用户主动导出后的第三方应用处理，不属于应用可控制的范围。卸载应用或清除应用数据会删除本地文稿。

## 功能

- 文稿新建、搜索、置顶、删除
- 标题与正文自动保存
- 粗体、斜体、标题、引用、项目符号、编号列表所见即所得
- PDF、Word 兼容文档（`.doc`）、JPG 长图导出
- 本机主副本与恢复副本自动修复
- 无应用锁，打开后直接使用

## 本地运行

```bash
npm install
npm run android
```

iOS 构建需要 macOS 与 Xcode。生物识别、安全存储和截屏防护应在开发构建或正式构建中测试，Expo Go 只适合基础界面预览。

## Android 安装包

已生成的本地安装包位于 `artifacts/Mojian-1.2.0-android.apk`。该包支持 Android 7 及以上系统，使用项目专属的 4096 位 RSA 签名身份，并已移除联网、网络状态、生物识别、悬浮窗和外部存储权限。

签名身份保存在忽略提交的 `.private-signing/` 目录。后续版本必须继续使用同一签名才能覆盖安装；请妥善备份该目录，不要公开分享。其中的密码文件由 Windows DPAPI 加密，只能由当前 Windows 用户解密。
