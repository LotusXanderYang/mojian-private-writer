# 墨笺

一款离线优先、隐私优先的手机写作应用。界面采用“纸墨书房”风格，支持所见即所得富文本编辑、自动加密保存，以及 PDF、Word、JPG 三种导出格式。

## 隐私设计

- 无账号、无埋点、无云同步代码。
- Android 正式构建移除 `INTERNET` 权限。
- 文稿通过 AES-GCM 加密后写入本地存储。
- 加密密钥优先存入 iOS Keychain / Android Keystore 支持的安全存储，并在应用私有沙箱保留兼容恢复副本，避免安全存储偶发失效造成日常文稿无法打开。
- 启动和离开应用后要求设备锁验证。
- 默认阻止截屏和录屏；仅生成 JPG 的瞬间临时放行，分享完成后立即恢复。
- 只有用户主动选择导出时，明文文件才会交给系统分享面板；临时 Word/JPG 文件随后删除。

> 安全边界：兼容恢复副本提高了可用性，但安全强度低于“仅硬件密钥”。它和密文都受系统应用沙箱保护。Android/iOS 原生正式版是目标平台；越狱、Root、恶意系统组件或用户主动导出后的第三方应用处理，不属于应用可控制的范围。

## 功能

- 文稿新建、搜索、置顶、删除
- 标题与正文自动保存
- 粗体、斜体、标题、引用、项目符号、编号列表所见即所得
- PDF、Word 兼容文档（`.doc`）、JPG 长图导出
- 系统生物识别或设备密码解锁
- 回到后台自动锁定

## 本地运行

```bash
npm install
npm run android
```

iOS 构建需要 macOS 与 Xcode。生物识别、安全存储和截屏防护应在开发构建或正式构建中测试，Expo Go 只适合基础界面预览。

## Android 安装包

已生成的本地安装包位于 `artifacts/Mojian-1.1.0-android.apk`。该包支持 Android 7 及以上系统，使用项目专属的 4096 位 RSA 密钥签名，并已移除联网、网络状态、悬浮窗和外部存储权限。

签名身份保存在忽略提交的 `.private-signing/` 目录。后续版本必须继续使用同一签名才能覆盖安装；请妥善备份该目录，不要公开分享。其中的密码文件由 Windows DPAPI 加密，只能由当前 Windows 用户解密。
